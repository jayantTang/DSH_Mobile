# TC-MOB-107 过程折叠（展开/收起的视口锚点）

对应改动：过程节点在展开/收起两种状态下都保留原位置与身份；读者停在某一行时，
切换折叠不得把视口甩到顶部或底部。

**做法**：在临时会话里制造一轮带工具的过程；先把视口停在过程节点附近，再连续
展开/收起，截图对照顶部行。

## 步骤

1. 连上本机 DSH，用固定夹具直达临时会话。
2. 截图（收起态）。
3. 点第一轮的过程节点展开，截图。
4. 再点同一节点收起，截图；确认该节点仍在视口内。

## 说明

执行指令在同名 `.steps` 文件里；没有授权仿真器时不执行，报告记 blocked。
