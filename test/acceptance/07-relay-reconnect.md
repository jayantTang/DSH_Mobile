# TC-MOB-93 链路抖动：掉线自己接回来，不崩、不堆 socket

仿真器切不了蜂窝/Wi-Fi，所以「链路抖动」用协议层的 DEBUG 钩子从手机侧制造：
`-DSHLinkFlap 2` 让 `LinkCarrier` 在连上后各掐断两次。要验的是用户真正会遇到的那两件事——
**它能不能自己接回来**，以及**会不会叠出第二条 socket**（2026-10-12 与 10-14 两次线上抖动
都是后者）。
