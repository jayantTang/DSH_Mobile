# TC-MOB-106 过程折叠（已完成轮次默认收起）

对应改动：已完成的轮次把过程（工具调用、思考、中间说明）收进一个过程节点，

**边界**：使用运行器新建的临时会话，不碰真实会话；不点任何待答问题。

## 步骤

1. 连上本机 DSH，用 `-DSHOpenSession -DSHProbeProcessFoldFixture` 直达临时会话；夹具含两轮已完成过程。
2. 截图，确认过程节点存在，工具卡不在屏幕上。
3. 点第一轮的过程节点，截图，确认工具卡出现且顺序与执行顺序一致。
4. 再点一次收起，截图，确认工具卡消失、问答仍在。
