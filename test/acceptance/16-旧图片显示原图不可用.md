# TC-MOB-145 旧图片显示原图不可用

背景：原图是按需取回的，前提是 Host 侧有「预览 id → 原图引用」的关联。功能上线前
发出的图片只有预览这一份附件。要求是**明说不可用**，而不是把预览当原图，也不是
把一次正常的"没有"显示成网络错误或永远转圈。

## 覆盖与不覆盖

- 覆盖：全屏默认预览；旧数据落成「原图不可用」终态；没有错误弹窗；可正常关闭。
- 不覆盖：Host 已清理对象文件（`cleaned`）与连接器不支持（`unsupported`）——
  两者在同一状态机里由单元用例覆盖，界面表现与本条相同。

## 步骤

1. 打开夹具会话的转写
2. 点图片缩略图，进入全屏
3. 等待 3 秒
4. 「原图不可用」出现在工具栏（终态，不再请求）
5. 截图留证
6. 点「完成」回到转写
7. 截图留证
