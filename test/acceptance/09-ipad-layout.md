# TC-IPAD-09 iPad 阅读宽度与横屏

横屏时详情列比 760pt 宽，正文与输入区要收进阅读宽度并居中
（左右留白各 =（详情列宽 − 760）/2）。

快捷键不在这一份用例里：它是另一套机制（场景命令），见 `ipad-04`；两者失败原因互不相干，
分开写才不会一项失败把另一项的结论吞掉。

## 步骤

1. 打开会话转写（`-DSHOpenSession` 在 iPad 上落到分栏），截图留证。

2. 确认转写与左侧列表同时在场。

3. 旋转到横屏，截图留证。

4. 确认转写仍在渲染。
