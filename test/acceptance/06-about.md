# TC-UI-103 设置「关于」四段版本（中文）

版本观测（035）落地后，设置页「关于」一节要能读出**四段独立发布的版本**：
App、连接器、DSH 宿主、中转。这四行是用户报问题时唯一的自述来源。

本用例只核对这一节：连接本机 DSH（走中转，与产品同一条通道）→ 从会话列表点「设置」
→ 滚到「关于」之下 → 截图。

- 为什么从列表点「设置」而不是直达：直达时连接尚未建立，「关于」里的连接器/DSH/中转
  三段永远是「未上报」（见 47/48 的说明）。
- 「中转版本」显示「未上报」是**允许**的：中转要先部署 035 才会在 `hostStatus` 里带
  `relayVersion`；这一行的存在与文案是本用例的核对对象，值本身不作为判据。
- 「连接器版本」必须是仓库当前的 `package.json` 版本（本次实测值写进报告）。

## 步骤

1. 连接本机 DSH，停在会话列表。
2. 点工具栏「设置」，等设置页弹出。
3. 滚到「在电脑端配置」（它在「关于」下面，滚到它时「关于」整块在屏内），截图留证。
4. 确认四行版本标签都在：App 版本、连接器版本、DSH 版本、中转版本。

## 说明

- 执行指令在同名的 `.steps` 文件里。
- 连接方式是**中转**；断言只覆盖「关于」一节的标签存在，具体值由截图人工核对。
