# 验收用例子集

这 17 条用例是 iOS 每次发版前必须执行的固定子集，纳入版本控制，避免落进
`test/cases/` 后被本机清理或腐化。

| 用例 | 覆盖 |
|---|---|
| `01-chat-send` | 临时会话发送、输入清空、回显、上拉 |
| `02-chat-paging` | 真实宿主上拉补页；错误条必须不存在 |
| `03-chat-fold` | 已完成轮次默认收起 |
| `04-chat-send-state` | 发送后不永久停在等待开始 |
| `05-chat-fold-expand` | 过程折叠展开/收起锚点 |
| `06-about` | 关于页四段版本 |
| `07-relay-reconnect` | 强制断链后自愈、不崩 |
| `08-text-wrap` | 文本换行开关与关闭后的横向滚动 |
| `09-ipad-layout` | iPad 分栏阅读宽度与横屏 |
| `11-connector-install-guide` | 连接器安装指引 |
| `13-settings-permission` | 设置页权限档位 |
| `14-background-resume` | 手机回前台恢复 |
| `15-会话图片原图按需下载` | 全屏默认预览、按需下载原图、保存预览/原图 |
| `16-旧图片显示原图不可用` | 旧数据只有预览时「原图不可用」 |
| `17-相册未授权保存提示` | 相册未授权时的说明与「打开设置」 |
| `18-手机发送图片保留原图` | 手机发图时预览与原图成对落地 |
| `19-未查看原图直接保存` | 未看原图也能先下载再保存 |

## 执行

```bash
DSH_CONNECT=relay npm run test:acceptance
```

运行器只从本机真实宿主/中转取证据；没有宿主时不得伪造通过。每条都按
`test/rules/REPORT-CONTRACT.md` 出 `review.md` 与 `report.html`。

## 失败分诊

- 产品：截图/探针显示用户可见行为错误，登记缺陷并修复，不能改用例绕过。
- 用例：fixture 失效、选择器过期、截图时机错误，修用例并重跑。
- 环境：宿主未启动、中转配对失败、模拟器异常，重跑；连续两次才记为环境阻塞。

## 固定会话

发送类使用 `临时目录`；只读类由运行器挑选会话。必须有特定夹具（图片原图、旧数据等）
的用例可以钉住一个 `会话:`，但 `备注` 必须写清夹具重建命令（`scripts/dev/image-scratch-
session.mjs …`）与用完的清理方式，正文与指令里不得出现别的会话 id。
