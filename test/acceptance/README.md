# 验收用例子集

这 6 条用例是 iOS 每次发版前必须执行的固定子集，纳入版本控制，避免落进
`test/cases/` 后被本机清理或腐化。

| 用例 | 覆盖 |
|---|---|
| `01-chat-send` | 临时会话发送、输入清空、回显、上拉 |
| `02-chat-paging` | 真实宿主上拉补页；错误条必须不存在 |
| `03-chat-fold` | 已完成轮次默认收起 |
| `04-chat-send-state` | 发送后不永久停在等待开始 |
| `05-chat-fold-expand` | 过程折叠展开/收起锚点 |
| `06-about` | 关于页四段版本 |

## 执行

```bash
DSH_CONNECT=relay npm run test:acceptance
```

运行器只从本机真实宿主/中转取证据；没有宿主时不得伪造通过。每条都按
`test/REPORT-CONTRACT.md` 出 `review.md` 与 `report.html`。

## 失败分诊

- 产品：截图/探针显示用户可见行为错误，登记缺陷并修复，不能改用例绕过。
- 用例：fixture 失效、选择器过期、截图时机错误，修用例并重跑。
- 环境：宿主未启动、中转配对失败、模拟器异常，重跑；连续两次才记为环境阻塞。

## 固定会话

验收用例不得写死 `会话:`。发送类使用 `临时目录`；只读类由运行器挑选会话。
