# TC-MOB-22 Git 变更与历史

用户要的是「基于目录看 git 差异 + 看历史、能点开历史版本的文件」。这条用例走完整条链路：
连接器在本机跑只读 git（`plugins/mobile-link/lib/git.js`），App 把状态、单文件差异、提交历史、
以及某个提交里某个文件的正文读出来。

## 覆盖与不覆盖

- 覆盖：变更列表（分支名、4 处改动、按目录分组、状态字样）、单文件差异（+/− 行）、
  提交历史（列出两次提交）、提交详情的文件清单、某个提交里某文件的差异、该文件在该版本的正文。
- 不覆盖：二进制差异（夹具里没有二进制，连接器单测覆盖）、超大 diff 截断（单测覆盖）、
  分支切换（产品上不做，交给 agent）、任何写操作（命令白名单里根本没有）。
- 夹具是 `/tmp/dsh-git-demo` 下的临时仓库，由 `test/fixtures/git-demo/setup.sh` 生成，跑完随会话清理；
  电脑上其他仓库一个字节不动（所有 git 调用都是只读，且带 `GIT_OPTIONAL_LOCKS=0`）。

## 步骤

1. 打开工作区文件页
2. 切到「变更」标签：给出分支名与 4 处改动
3. 截图留证（变更列表）
4. 点开 notes.txt 的差异：出现工作区里那句改动
5. 截图留证（差异页的 +/− 行）
6. 关闭差异、切到「历史」：列出两次提交
7. 打开「初始提交：夹具仓库」：文件清单里有 README.md
8. 截图留证（提交详情）
9. 点开该提交里的 README.md：出现这次提交里的差异
10. 点「该版本文件」：显示的正文只存在于第一次提交
11. 截图留证（历史版本文件）
