# TC-MOB-01 手机上阅读测试报告

从工作区文件打开 HTML 测试报告，确认它在手机上被当作网页正确渲染：中文正常、
版式与 Mac 一致、6 张截图都取到了。

## 步骤

1. 从工作区文件打开报告（HTML 默认进渲染查看）

2. 确认渲染出的报告正文在屏幕上

3. 确认顶部的查看方式切换器在（预览 / 源码）

4. 确认判定一节渲染出来

5. 确认 6 张截图都取到了（取图失败会出现「没取到附件」横幅，没有即全部成功）

6. 尝试切换为源码查看

7. 确认渲染查看没有被切走（切换按钮目前点不中，见下）

## 说明

- 验证入口是 `test/fixtures/` 下的 fixture：`test/fixtures/test-report-fixture.html` 与 `media/`
  （某次真实报告与它预览图的副本）。单独放一份是为了让用例不绑死在某次运行的目录上。
- 渲染模式由 App 的 `-DSHOpenFile` 钩子直达，与测试框架启动页面的方式一致；
  页面本身仍是同一份实现。
- 第 6 步按屏幕坐标点击：切换按钮在 Web 视图的工具栏里，不暴露稳定的点击目标，
  目前点不中——见 `test/CAPABILITY-GAPS.md` 交互-3。因此第 7 步断言的是
  「没有证据表明它被切走」，而不是「切成功了」。
- 源码查看由阅读器既有能力提供（无预览能力的文件即走源码模式），本用例不覆盖。
- 与 Mac 的一致性靠人工并排比对（同一份 HTML + 同一套 CSS）。
