# TC-MOB-24 图片类工具卡片默认不显示参数

用户看到的现象：agent 发图之后，工具卡片里先把 `{"caption": "...", "screenshot": true}` 这种
参数 JSON 摆出来，图片反而在下面。参数对看图的人没有信息量。

现在的规则：**结果里带图片的工具卡片，参数默认收起**，底下留一个「显示参数」小按钮；
不带图片的卡片（bash、read、grep 等）参数照旧直接显示——那里参数就是内容本身。

## 覆盖与不覆盖

- 覆盖：带图片的卡片展开后不出现「参数」标题与 JSON；「显示参数」按钮存在；点开后参数出现、
  按钮文案翻转；截图留证。
- 不覆盖：参数被真正删除（它没有：仍然一键可见）；其他客户端的渲染（Web 端不归这条用例管）。

## 步骤

1. 打开这个会话的转写
2. 确认屏幕上没有参数 JSON（`caption` 只可能来自它）
3. 点击「显示参数」：按钮变成「隐藏参数」
4. 参数出现（那行 JSON 又回到了卡片里）
5. 截图留证：参数显示出来的样子
6. 再点一次「隐藏参数」：按钮变回「显示参数」
7. 参数 JSON 又不见了
8. 截图留证：收起后的样子
