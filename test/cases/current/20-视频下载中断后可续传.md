# TC-MOB-20 视频下载中断后能续传

用户要求：下载失败不能从头再来，要像正经下载器那样接着下。

一次真实的中断（中转把设备踢掉）没法在用例里排期，所以用 DEBUG 专有的
`-DSHInterruptDownload <bytes>` 在第一窗口之后切断第一次尝试：留下的字节数是确定的
（一个 2 MiB 窗口 = 2097152），于是「续传从 2097152 起」这件事可以被精确断言，而不是靠印象。

## 覆盖与不覆盖

- 覆盖：中断后状态是「已保存 + 继续/放弃」而不是丢弃；点「继续」后接着下完，最终字节数与文件一致。
- 不覆盖：真实网络抖动导致的中断（同一套代码路径，但触发时机不可控）；自动重试（用例走的是人工点「继续」那条）。
- 中断由 DEBUG 钩子制造，Release 包里没有这些参数：`-DSHForgetDownloadedFiles` 先清掉上一轮
  留下的缓存（否则命中缓存，一个窗口都不拉），`-DSHInterruptDownload` 再切断第一次尝试。

## 步骤

1. 带中断参数打开这个视频：阅读页出现，标题是文件名
2. 等第一次尝试被切断：状态条显示已保存 2097152 字节（一个 2 MiB 窗口）
3. 截图留证（中断态：已保存字节数、百分比、继续/放弃按钮）
4. 点「继续」：下载接着已保存的字节下完，进入「已可分享」
5. 截图留证（续传完成后的状态条）
