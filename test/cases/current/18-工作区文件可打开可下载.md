# TC-MOB-18 工作区文件能打开、能下载

改动前：工作区文件只认 UTF-8 文本，点图片、pdf、zip 一律得到「这不是一个 UTF-8 文本文件」，
并且整条链路上没有任何把文件落到手机上的能力。

改动后按类型分流：图片全屏打开（可双击/捏合缩放），pdf/office/zip 等交给系统预览；
两类都能「下载」到手机上，下载完成后再点一次「分享」走系统面板存到「文件」或发给别的 App；
系统预览打不开的格式显示文件信息卡（名称、大小、**精确字节数**、分享）。

## 覆盖与不覆盖

- 覆盖：图片（原生预览）、pdf（系统预览）、zip（列表里点行进入 → 信息卡）、
  3 MiB 二进制（比一个 2 MiB 字节窗口大，靠两次窗口拼接，界面显示精确字节数）、
  纯文本（阅读器回归 + 文本也能下载）。
- 不覆盖：系统分享面板里的具体动作（「存储到文件」、AirDrop）——面板是系统进程的 UI，
  用例驱不动，只截图留证；跨设备投送同理。
- 3 MiB 夹具是运行前生成的临时文件（`test/runs/` 不入库）：
  `python3 -c "import random;random.seed(20260918);open('test/runs/fixtures/paging-3mb.bin','wb').write(random.randbytes(3*1024*1024+64*1024))"`。
- 大文件经中转下载的耗时取决于这台电脑的上行带宽，用例给的是 240 秒上限，不是期望值。

## 步骤

1. 打开一张工作区图片：出现全屏大图，且不再出现「不是 UTF-8 文本」的错误文案
2. 打开 sample.pdf：等它下载完成，并且没有旧错误文案
3. 点「分享」：系统分享面板出现
4. 打开工作区文件页，看到目录列表
5. 进入 test 目录，看到 fixtures 行
6. 进入 fixtures 目录，看到 sample.zip 行
7. 点开 sample.zip：出现信息卡，字节数 321
8. 打开 3 MiB 二进制夹具：阅读页出现，标题是文件名
9. 等它下载完：界面显示 3211264 字节（一个 2 MiB 窗口装不下，靠分窗拼完整）
10. 打开 markdown 表格夹具：源码阅读器照常显示正文，且没有旧错误文案
11. 点「下载」并等它完成：状态条出现「已下载 … 字节」，说明文本文件也能下载
