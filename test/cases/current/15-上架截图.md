# TC-DEMO-02 App Store 上架截图

上架要的是**原图**（本例是 1206×2622，对应 iPhone 17 Pro / 6.9" 那一档），不是 README 用的
压缩图。同时上架素材不能含真实数据，所以复用 `TC-DEMO-01` 那套合成会话与脱敏开关。

## 与 TC-DEMO-01 的分工

| | TC-DEMO-01 | TC-DEMO-02（本用例） |
|---|---|---|
| 用途 | 仓库 README 配图 | App Store Connect 截图 |
| 尺寸 | 缩到 460×1000、压成 jpg，入库 | 原图 PNG，**不入库**（发布产物） |
| 张数 | 2 张 | 4 张（转写 / 文件 / 设置 / 连接） |
| 会话列表 | 拍但不入图（含真实项目名） | 不拍 |

## 步骤

1. 连接本机 DSH（不截图）。

2. 打开合成会话的转写，截图留证。

3. 打开工作区文件页，截图留证。

4. 打开设置页（`-DSHDemoMode`：中转地址与主机主目录换成占位符），截图留证。

5. 打开连接管理页（配对表单），截图留证。

## 说明

- 生成合成会话：`node scripts/dev/demo-session.mjs`（打印会话 id，填进本文件的 `会话:`）；
  用完 `node scripts/dev/demo-session.mjs --cleanup-all`。
- **必须 `DSH_CONNECT=relay`**：上架截图里的连接方式要和产品一致（设置页要显示「中转」）。
- 导出的原图在 `test/runs/<运行>/shots/`，App Store Connect 上传时的要求与尺寸换算见
  `docs/notes/APPSTORE.md`。
