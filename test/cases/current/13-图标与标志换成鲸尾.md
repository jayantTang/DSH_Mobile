# TC-UI-02 App 图标与连接页标志换成鲸尾

图标此前是一只卡通鲸：圆头、笑脸、三颗喷潮，缩到桌标尺寸读起来像贴纸。这一版换成
**举起的鲸尾**——两片叶 + V 形缺口 + 短尾柄，参照 DeepSeek 官方 App 图标的做法：
白标志、品牌蓝、柔和立体（受光面高光 + 背光面内阴影 + 一层浅投影）、大量留白。

标志由 `scripts/dev/make-app-icon.py` 画出（几何写在 `TAIL_HALF` 里，右半边镜像生成），
同时出三样东西：桌面图标（浅色/深色）、App 内用的模板图 `TailMark`。本用例核对
**界面这一侧**：App 装得上、起得来，连接页品牌区显示的是同一个形状。

## 步骤

1. 连接本机 DSH，进入会话列表，截图留证

2. 确认列表页的工具栏入口齐全

3. 打开连接管理页，截图留证

4. 确认连接页品牌区是「DSH Mobile」+ 标志，配对表单在

## 说明

- **桌面图标不在本用例的步骤里**：XCUITest 驱动不了桌面，图标是启动前用
  `xcrun simctl io screenshot` 拍的（浅色与深色各一张，已放进本次运行的 `shots/`），
  第 1 步的判定依据引用它们。
- 图标有缓存：换图后必须 `simctl uninstall` 再装，否则拿到的是旧图。
- 执行指令在同名的 `.steps` 文件里，本文件只描述用例本身。
