# TC-APP-04 已归档会话可在列表里找回

归档把会话移出工作区分组界面。它必须仍然找得到——否则「整理旧会话」就变成了
「弄丢旧会话」。列表底部的「已归档」折叠区就是它的去处：展开后能看到、能打开。

归档那个动作本身由 TC-APP-02 验证（左划 + 点归档）。这里由运行器预先把临时会话
设成归档状态，只验证「找得回、打得开」这件事。

（此版本的 DSH 没有取消归档的接口：`workspace/archiveSession` 接受 `archived:false`
但忽略它，注册表也只有 archiveSession 一个方法。所以能验证的是「找得回」，
不是「能取消归档」。）

## 步骤

1. 连接本机 DSH，确认列表在

2. 确认这个归档的会话不在工作区列表里（它已从分组界面移走）

3. 滚到列表底部的「已归档」，截图

4. 展开「已归档」

5. 确认刚才那个会话在里面，截图

6. 点开它

7. 确认能进入该会话：输入框出现

8. 截图留证
