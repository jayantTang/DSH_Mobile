# TC-APP-03 按现有项目目录新建会话并进入

手机上要能接着一个已有项目开工。右上角「新建会话」列出 host 已知的项目目录
（工作区 + 现有会话的工作目录），选一个就在那个目录里新建会话。

**并且新建之后必须真的进入那个会话**：只关掉弹层、列表上多一行没有标题的空会话，
等于没做成——用户认不出哪一行是它，也回不到刚开的那个。

新会话还必须归到它所在的那个目录分组下。会话归属由主机的 workspace 决定：用 `cwd`
建出来的会话不属于任何 workspace，桌面上和手机上都只会落在「未分组」。所以这里要
看到它在该目录的工作区分组里，而不是未分组里。

## 步骤

1. 连接本机 DSH，确认列表在

2. 点右上角「新建会话」，确认弹层打开

3. 确认弹层里列出了项目目录

4. 滚到临时目录那一条

5. 点它新建

6. 等弹层关闭

7. 确认进入新会话：输入框出现

8. 截图留证会话界面

9. 重新打开会话列表，滚到临时目录那一组

10. 确认新会话归在该目录的工作区分组下，不在「未分组」里，截图留证
