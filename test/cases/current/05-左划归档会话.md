# TC-APP-02 左划归档会话

会话列表只增不减，旧会话会挤掉正在做的工作。左划一行选择归档，把它从工作区
列表里收走，并提示可以在电脑端找回。全程用运行器创建的临时会话，不动真实历史。

归档在 host 侧是单向的：`workspace/archiveSession` 接受 `archived:false` 但忽略它，
也没有 unarchive 方法，所以这里不做撤销，也不做撤销按钮。

## 步骤

1. 连接本机 DSH，确认列表在

2. 滚到列表底部找到「未分组」

3. 展开「未分组」，确认临时会话在里面

4. 左划该行，露出归档按钮

5. 点击「归档」

6. 确认该行消失、并出现已归档提示
