# TC-MOB-28 换会话后图片仍能加载

背景：附件图片缓存按 `attachmentId` 取图，而 `AttachmentImages.reset()` 写好了**从没被调用**
——最多 24 张别的会话（甚至另一台电脑）的图片一直留在缓存里。现在换会话与换连接都会清掉它。

这一条验的是**清得对**：清掉之后回到甲，甲的图片必须还能重新加载出来（如果只清不重载，
用户看到的就是空白）。

## 覆盖与不覆盖

- 覆盖：甲里图片显示 → 切到乙：乙的图片显示 → 切回甲：甲的图片**重新加载显示**。
- 不覆盖：跨连接（换另一台电脑）的清理——本机只有一个已配对身份，真造第二台要另一个账号，
  本轮没做；那一段靠代码审查（`forgetConnection()` 的调用点在 `syncConnectionState` 的
  「主动切换/断开」分支里）。`capabilities` 与 `SessionViewLog` 的作用域同理，未在 UI 里验。

## 步骤

1. 连接本机 DSH，看到会话列表
2. 滚到未分组
3. 展开未分组
4. 滚到会话甲那一行
5. 进甲：等待图片显示出来
6. 截图留证：甲里的图片
7. 退回列表
8. 滚到会话乙那一行
9. 进乙：等待图片显示出来
10. 截图留证：乙里的图片
11. 退回列表
12. 往下拽两屏（甲在乙上面，`滚动到` 只往下滚）
13. 滚到会话甲那一行
14. 再进甲：等待图片再次显示出来
15. 截图留证：缓存清掉之后重新加载成功
