# TC-APP-06 从未用过的空会话不进列表

新建会话会在 host 上立刻落一条记录：会话先存在，第一条消息才让它有内容。
点开又没发消息的那些会话就永远停在这个状态——host 把这种会话标成 `blank`，
客户端电脑端的侧栏只把它当成「当前这一次新建」的占位行，从不留在列表里。

手机端此前把它们当普通行渲染：标题回落成「新会话 · <目录名>」，没有 token 用量，
状态点是灰的，于是每个用过的分组里都可能挂着一条再也没有下文的灰行。本用例
验证这条规则搬到了手机上——**没有消息、也没被打开的空会话不进列表**。

判定看两处：真的造一条这样的会话（运行器的临时目录），它必须找不到；同时
首屏截图里真实存在的那些灰行也必须不见。

## 步骤

1. 连接本机 DSH，进入会话列表，截图留证

2. 滚到列表底部的「未分组」

3. 展开「未分组」，让折叠区里的行都渲染出来

4. 确认运行器造的那条空会话不在列表里，截图留证
