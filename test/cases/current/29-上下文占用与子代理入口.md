# TC-MOB-29 上下文占用与子代理入口

用户的两个问题：右侧那条小进度条是什么（＝上下文占用，>75% 才出现，但没人看得懂）、
以及「👥 3」是什么（＝子代理记录数，展开后是一串英文提示词当标题的行，看不出价值）。

处理：占用超过阈值时改成小字「上下文 N%」；会话信息气泡里加「上下文占用」（精确 token +
占比 + 进度条）；**子代理列表整个入口去掉**（用户判断没有可操作的价值）。

## 覆盖与不覆盖

- 覆盖：列表行的小字占用、信息页的占用行、子代理入口消失。
- 不覆盖：占用低于阈值时列表行应当**不显示**任何占用信息（本轮只验了超阈值的那一行；
  低占用行为靠代码条件 `fraction > 0.75` 审查）。

## 步骤

1. 连接本机 DSH，看到会话列表
2. 确认第一组里那行有「上下文 N%」小字
3. 截图留证：列表里的小字
4. 点开那一行进入转写
5. 点右上角会话信息
6. 确认信息页里有「上下文占用」（精确 token 与占比）
7. 截图留证：信息页
8. 退回列表，滚到有子代理的那个会话
9. 确认它右侧没有子代理小片，截图留证
