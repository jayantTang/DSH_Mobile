# TC-APP-04 在已有工作区目录里新建会话并归到该分组

用户报的问题就是这个：手机上挑一个已经有工作区的项目目录新建会话，新会话却出现在
「未分组」里。原因是 App 用 `cwd` 建会话——主机只把带 `workspaceId` 的会话挂进工作区，
不带就谁的都不是，桌面上也一样显示未分组。

所以这里要看到两件事：新会话能建出来并直接进入；重新打开列表时它在该工作区的分组下，
而不是「未分组」里。运行器先把临时目录登记成工作区，所以它出现在弹层的「工作区」一节。

## 步骤

1. 连接本机 DSH，确认列表在

2. 点右上角「新建会话」，确认弹层打开

3. 确认弹层里列出了「工作区」，临时目录在其中

4. 点它新建

5. 等弹层关闭

6. 确认进入新会话：输入框出现

7. 重新打开会话列表，滚到该工作区分组

8. 确认新会话在这个分组下，不在「未分组」里，截图留证
