# 需求

> 只有叶子是需求，分支标题只界定范围。每条写用户可观察行为与验收标准；需求编号即层级路径，供测试与提交引用。实现方案不写在此。

## 1 连接

### 1.1 登记

#### 1.1.1 开放登记

连接器在「移动端连接」面板登记，向中转换取身份，不需要邀请码；无头或自动化安装可用命令行登记。

验收：新用户不输入邀请码即可完成登记；同一来源每小时超过 5 次登记时返回 `enroll/rate-limited`。

#### 1.1.2 旧邀请码兼容

带邀请码的登记请求仍可用，但只服务旧版本与旧数据，新用户不经过该路径。

验收：带有效旧邀请码的登记成功；新用户界面不要求邀请码。

### 1.2 配对

#### 1.2.1 扫码配对

连接器展示包含中转地址与配对码的二维码，手机扫码或手输后建立配对并取得设备令牌。

验收：扫码后完成配对；配对码在面板重开与宿主重启后保持不变，只有用户点「重新生成」才更换。

#### 1.2.2 自动重连

配对成功后，手机再次打开时自动连接，无需重复配对。

验收：App 重启后直接进入已连接状态；网络中断恢复后自动重连。

### 1.3 设备管理

#### 1.3.1 设备列表与撤销

用户可查看已配对设备（含离线设备），并可撤销；撤销后该设备无法继续连接。

验收：撤销后该设备连接被拒绝；重新连接需要重新配对。

### 1.4 传输

#### 1.4.1 仅经公网中转

手机与电脑只通过公网中转建立连接，不提供直连或局域网入口；电脑无需公网 IP 或 VPN。

验收：客户端只有中转配对入口；链路经过 relay。

#### 1.4.2 测试与产品同通道

测试使用的连接通道与产品一致，不使用测试专用旁路。

验收：测试用例走同一 relay；不存在测试专用连接方式。

## 2 会话

### 2.1 会话访问

#### 2.1.1 查看并继续会话

手机可列出电脑上的会话，查看与电脑一致的消息流，并向当前会话发送消息。

验收：同一会话在两端显示一致；手机发送的消息出现在电脑端同一会话。

#### 2.1.2 电脑锁屏后继续运行

电脑锁屏或手机端暂时离开时，会话任务继续在电脑上运行。

验收：锁屏期间任务不中断；重新打开手机可看到最新状态。

### 2.2 待答

#### 2.2.1 待答提醒与作答

电脑端产生待答问题时，已连接的手机收到提醒并可作答；作答后电脑端继续执行。

验收：手机在线时收到待答；作答后电脑端任务继续。

已知限制：手机离线期间产生的待答不会补送，详见 `details/sessions.md`。

## 3 工作区

### 3.1 文件与 git

#### 3.1.1 查看远程文件

手机可查看电脑工作区的文件内容。

验收：选择文件后显示内容；文件不存在或不可读时给出错误提示。

#### 3.1.2 查看 git 改动与提交历史

手机可查看工作区的 git 改动与提交历史。

验收：改动列表与电脑端一致；提交历史可查看。

## 4 分发与更新

### 4.1 TestFlight 唯一渠道

#### 4.1.1 用户版本只经 TestFlight

用户安装与升级只通过 TestFlight；不提供 OTA 安装入口。

验收：公开渠道只有 TestFlight 链接；对外文档、信件、截图与帮助文案不含 OTA 地址。

### 4.2 版本

#### 4.2.1 TestFlight 阶段版本号固定 1.0

TestFlight 阶段 `MARKETING_VERSION` 保持 `1.0`，只用构建号区分；每次发布递增 `CURRENT_PROJECT_VERSION`，格式 `yyyyMMdd.HHmm`。

验收：每次发布构建号递增；营销版本保持 `1.0`。

### 4.3 发布

#### 4.3.1 发布包含提交外部测试审核

「发布 TestFlight」指上传、加入 Public beta 组、提交外部测试审核；审核通过后外部测试者可通过公开链接下载。

验收：只上传不提交审核不算发布；审核通过后公开链接指向新构建。
