# 需求

> 层级：IR 初始需求（目标与成功度量）、SR 系统需求（对外可测试行为）、AR 分配需求（组件职责与验收）。
> AR 只写职责与验收，不写实现结构；AR 编号前缀即其父 SR，不再写关联字段。编号按层级追加，结构调整属于破坏性变更，需 owner 确认并同步引用。

- **IR-01 连接可用**
  - **目标**：用户无需公网 IP 或 VPN，用手机连接自己电脑上的 DSH。
  - **成功度量**：新用户按引导完成登记与配对；网络中断恢复后无需重新配对。
  - **SR-01.01 开放登记**
    - **行为**：连接器在「移动端连接」面板登记，向中转换取身份，不需要邀请码；无头或自动化安装可用命令行登记。
    - **约束**：同一来源每小时超过 5 次登记时返回 `enroll/rate-limited`。
    - **验收**：新用户不输入邀请码即可完成登记；超限请求被拒绝并给出原因。
    - **AR-01.01.01 连接器登记职责**
      - **模块**：连接器
      - **职责**：发起登记，保存拿到的身份，并在面板显示登记状态。
      - **验收**：登记成功后身份持久化；面板显示已登记或失败原因。
    - **AR-01.01.02 中转登记职责**
      - **模块**：中转
      - **职责**：为每次登记创建账户与电脑，并执行来源限流。
      - **验收**：登记成功后账户与电脑可用；超限来源收到明确错误。
  - **SR-01.02 旧邀请码兼容**
    - **行为**：带邀请码的登记请求仍可用，但只服务旧版本与旧数据，新用户不经过该路径。
    - **验收**：带有效旧邀请码的登记成功；新用户界面不要求邀请码。
  - **SR-01.03 扫码配对**
    - **行为**：连接器展示包含中转地址与配对码的二维码，手机扫码或手输后建立配对并取得设备令牌。
    - **验收**：扫码后完成配对；配对码在面板重开与宿主重启后保持不变，只有用户点「重新生成」才更换。
    - **AR-01.03.01 连接器出码职责**
      - **模块**：连接器
      - **职责**：生成并持久化配对码，展示二维码；用户重新生成时换码，不作废已配对设备。
      - **验收**：面板重开、宿主重启后仍是同一张码；重新生成后新码可配对，旧设备仍在线。
    - **AR-01.03.02 中转配对职责**
      - **模块**：中转
      - **职责**：签发配对码、兑换配对码，并签发设备令牌。
      - **验收**：有效码可兑换；无效或过期码被拒绝。
    - **AR-01.03.03 App 配对职责**
      - **模块**：iOS App
      - **职责**：扫码或手输配对码，完成兑换并进入已连接状态。
      - **验收**：扫码成功后可看到电脑会话；失败时显示可重试的错误。
  - **SR-01.04 自动重连**
    - **行为**：配对成功后，手机再次打开时自动连接，无需重复配对。
    - **验收**：App 重启后直接进入已连接状态；网络中断恢复后自动重连。
    - **AR-01.04.01 App 重连职责**
      - **模块**：iOS App
      - **职责**：启动与网络恢复时使用已存令牌重连，失败进入可重试状态。
      - **验收**：冷启动恢复连接；断网恢复后无需手动配对。
  - **SR-01.05 设备列表与撤销**
    - **行为**：用户可查看已配对设备（含离线设备），并可撤销；撤销后该设备无法继续连接。
    - **验收**：撤销后该设备连接被拒绝；重新连接需要重新配对。
    - **AR-01.05.01 中转设备管理职责**
      - **模块**：中转
      - **职责**：返回含离线设备的全量列表，执行设备撤销。
      - **验收**：列表包含离线设备；撤销后该设备令牌失效。
    - **AR-01.05.02 客户端撤销入口**
      - **模块**：iOS App、连接器面板
      - **职责**：展示设备列表并提供撤销入口。
      - **验收**：两个入口都能看到设备并完成撤销。
  - **SR-01.06 仅经公网中转**
    - **行为**：手机与电脑只通过公网中转建立连接，不提供直连或局域网入口；电脑无需公网 IP 或 VPN。
    - **验收**：客户端只有中转配对入口；链路经过 relay。
  - **SR-01.07 测试与产品同通道**
    - **行为**：测试使用的连接通道与产品一致，不使用测试专用旁路。
    - **验收**：测试用例走同一 relay；不存在测试专用连接方式。

  - **SR-01.08 已保存连接**
    - **行为**：配对成功后保存连接；用户可在连接页看到已保存的电脑，切换或删除。
    - **验收**：配对后出现在已保存连接；切换后会话列表来自该电脑；删除后不再出现在列表。
    - **AR-01.08.01 App 连接管理职责**
      - **模块**：iOS App
      - **职责**：保存连接配置，展示列表，执行切换与删除。
      - **验收**：列表与当前连接一致；切换后进入对应电脑；删除后配置消失。

  - **SR-01.09 连接状态**
    - **行为**：界面显示当前连接状态（已连接、连接中、电脑离线）与主机地址。
    - **验收**：状态变化可见；电脑离线时给出可重试入口。
    - **AR-01.09.01 App 状态展示职责**
      - **模块**：iOS App
      - **职责**：展示连接状态与主机信息，提供重试入口。
      - **验收**：三种状态可见；离线时可重试。

  - **SR-01.10 账户设备上限**
    - **行为**：一个账户最多 8 台已配对客户端；达到上限时拒绝新增配对，并提示先撤销。
    - **验收**：第 9 台配对被拒绝；撤销一台后可再配对。
    - **AR-01.10.01 中转限额职责**
      - **模块**：中转
      - **职责**：按账户执行设备上限，超限返回明确错误。
      - **验收**：超限被拒绝并给出原因。

  - **SR-01.11 连接器安装指引**
    - **行为**：连接页提供安装指引，列出桌面版与命令行 web 版的安装方式，并提示安装后回到扫码。
    - **验收**：指引入口可见；两种安装方式可读；关闭后回到连接页。
    - **AR-01.11.01 App 引导职责**
      - **模块**：iOS App
      - **职责**：展示安装步骤与返回入口。
      - **验收**：指引可打开与关闭。

- **IR-02 会话可用**
  - **目标**：手机能继续电脑上的会话，暂时离开后回到 App 可恢复并看到最新状态。
  - **成功度量**：同一会话在两端一致；在线时产生的待答可在手机作答。
  - **SR-02.01 查看并继续会话**
    - **行为**：手机可列出电脑上的会话，查看与电脑一致的消息流，并向当前会话发送消息。
    - **验收**：同一会话在两端显示一致；手机发送的消息出现在电脑端同一会话。
    - **AR-02.01.01 App 会话职责**
      - **模块**：iOS App
      - **职责**：展示会话列表与消息流，发送用户消息。
      - **验收**：列表与消息流可用；发送后本地出现待确认状态，成功后与服务端一致。
    - **AR-02.01.02 连接器会话转发职责**
      - **模块**：连接器
      - **职责**：把会话请求与事件流转发给电脑端 DSH。
      - **验收**：手机请求到达 DSH；DSH 事件回到手机。
  - **SR-02.02 手机端回前台后恢复**
    - **行为**：手机端暂时离开、应用退到后台后，重新回到 App 时恢复连接并显示最新会话状态。
    - **验收**：回前台后连接恢复；会话列表与当前会话显示最新状态。
  - **SR-02.03 待答提醒与作答**
    - **行为**：电脑端产生待答问题时，已连接的手机收到提醒并可作答；作答后电脑端继续执行。
    - **验收**：手机在线时收到待答；作答后电脑端任务继续。
    - 已知限制：手机离线期间产生的待答不会补送，详见 `details/sessions.md`。
    - **AR-02.03.01 App 待答职责**
      - **模块**：iOS App
      - **职责**：展示待答问题并把用户答案回传。
      - **验收**：在线时收到待答；提交后回到等待执行状态。
    - **AR-02.03.02 连接器待答转发职责**
      - **模块**：连接器
      - **职责**：把 DSH 的待答事件转给手机，把答案回传 DSH。
      - **验收**：待答到达手机；答案到达 DSH 并继续任务。

  - **SR-02.04 发送消息与打断**
    - **行为**：手机可发送消息；任务运行时可用打断停止当前任务。
    - **验收**：消息出现在两端；打断后任务停止，输入框可继续。
    - **AR-02.04.01 App 输入与打断职责**
      - **模块**：iOS App
      - **职责**：发送消息，提供打断动作。
      - **验收**：发送成功；打断生效。
    - **AR-02.04.02 连接器任务控制职责**
      - **模块**：连接器
      - **职责**：把消息与打断请求转给 DSH。
      - **验收**：请求到达 DSH；状态回到手机。

  - **SR-02.05 排队输入**
    - **行为**：任务运行时继续输入，消息进入队列；可逐条插入、撤回编辑或删除。
    - **验收**：运行中发送进入队列；插入后进入当前任务；撤回后回到输入框。
    - **AR-02.05.01 App 队列职责**
      - **模块**：iOS App
      - **职责**：维护队列，执行插入、撤回与删除。
      - **验收**：队列可见；三种操作生效。

  - **SR-02.06 会话内搜索**
    - **行为**：可搜索已加载的会话内容与「只看我的提问」，点结果跳转并高亮；未加载部分可继续向上加载后再搜。
    - **验收**：关键词命中；结果可跳转；切换「只看我的提问」生效。
    - **AR-02.06.01 App 搜索职责**
      - **模块**：iOS App
      - **职责**：本地搜索、结果跳转与补页。
      - **验收**：搜索可用；跳转定位正确；可继续加载更早内容。

  - **SR-02.07 发送图片、视频与文件**
    - **行为**：可从相册或文件选择图片、视频与其它文件发送到当前会话；图片在上限内同时保留原图和预览，模型只接收预览；超过原图上限或无法生成预览时按文件发送；失败给出原因。
    - **验收**：图片、视频与文件出现在两端；可查看预览并在需要时取回原图；超限图片以文件形式可下载；不可读文件提示失败。
    - **AR-02.07.01 App 附件选择职责**
      - **模块**：iOS App
      - **职责**：选择、预览、移除并发送附件；为图片生成预览并保留原图，上传进度可取消、可重试。
      - **验收**：附件可预览与移除；原图与预览成对上传；超限时转为文件；失败原因可见。
    - **AR-02.07.02 连接器附件转发职责**
      - **模块**：连接器
      - **职责**：转发原图、预览与文件，不静默改写原图；回传状态与大小。
      - **验收**：附件到达 DSH；原图与预览关联可追溯；超限按文件转发；失败原因回到手机。

  - **SR-02.08 运行结束与待答通知**
    - **行为**：运行结束或需要确认时提醒，只覆盖正式会话（属于工作区、未归档、非子会话）；点通知打开对应会话。手机不在线时由中转发送仅含会话 id 的推送。未分组、子会话与已归档的运行结束和待确认不产生本地通知，也不产生离线推送。
    - **验收**：正式会话两类事件各产生通知；未分组、子会话与已归档不产生通知或推送；点击进入会话；无通知权限时不弹。
    - **AR-02.08.01 App 通知职责**
      - **模块**：iOS App
      - **职责**：申请权限、只对正式会话投递本地通知、处理点击路由。
      - **验收**：非正式会话不投递；通知可见；点击直达会话。
    - **AR-02.08.02 中转推送职责**
      - **模块**：中转
      - **职责**：手机不在线时只对正式会话发送仅含会话 id 的 APNs 推送。
      - **验收**：非正式会话不推送；离线手机收到推送；点击后回到对应会话。
    - **AR-02.08.03 连接器提醒判定职责**
      - **模块**：连接器
      - **职责**：按会话是否属于正式会话决定是否上报运行结束与待答提醒；非正式会话不上报。
      - **验收**：未分组、子会话与已归档不产生离线推送；正式会话两类事件均上报。

  - **SR-02.09 通知偏好**
    - **行为**：可分别开关「运行结束时提醒」与「需要确认时提醒」；未授权时提示去系统设置。
    - **验收**：开关持久化；关闭后不再提醒；未授权时提示。
    - **AR-02.09.01 App 通知偏好职责**
      - **模块**：iOS App
      - **职责**：保存开关，按偏好决定是否提醒。
      - **验收**：开关生效并持久化。

  - **SR-02.10 代码与 HTML 内容展示**
    - **行为**：消息中的代码有语法高亮；HTML 报告可在应用内预览。
    - **验收**：代码块高亮；HTML 可打开预览。
    - **AR-02.10.01 App 内容渲染职责**
      - **模块**：iOS App
      - **职责**：渲染代码高亮与 HTML 预览。
      - **验收**：两类内容可读。

  - **SR-02.11 图片查看与保存**
    - **行为**：消息图片默认显示预览，点开全屏；全屏内只用捏合缩放与拖拽平移，不设双击快捷方式；捏合 1–6 倍，放大到约 1 图像像素对 1 屏幕像素时最清晰、再放大只增加插值；整屏时单击关闭，放大后单击不关闭。存在原图时提供「原图 · 大小」，点它才下载并显示进度、可取消；完成后画面切到原图并显示像素尺寸，再次打开直接复用。保存入口为菜单，可选「保存预览」「保存原图」；保存原图在点击时按需下载（未下载则先显示进度），不要求先查看原图。原图缺失、Host 已清理、旧数据只有一份或超过 20 MB 未保留时显示「原图不可用」，不报错、不自动重试、不用预览冒充；下载失败保留预览并可重试。工作区图片不设预览/原图两变体（见 SR-03.03、SR-03.04），回信附件沿用本查看器（见 SR-05.03），工具结果图片按 SR-02.12 折叠后不丢图。
    - **验收**：默认先显示预览；列表与打开会话不请求原图；点「原图」有进度、可取消，完成后画面与尺寸同时变化且再次打开不再下载；未查看原图时直接「保存原图」也能先下载再保存；下载失败仍保留预览并可重试；不可用时不弹错、不重试；保存可选预览或原图，未授权保存时提示；全屏没有双击快捷方式。
    - **AR-02.11.01 App 图片查看职责**
      - **模块**：iOS App
      - **职责**：区分预览与原图，默认加载预览，按需下载原图；提供捏合缩放、平移、保存预览/原图与失败回退；保存原图按需触发下载。
      - **验收**：默认不下载原图；查看原图有进度；保存原图可直接触发下载并可见进度；失败不丢失预览；权限缺失提示。
    - **AR-02.11.02 连接器图片变体职责**
      - **模块**：连接器
      - **职责**：持久化原图与预览的关联；重装、重新配对或换设备后仍可从 Host 取回预览和可用的原图。
      - **验收**：重装后历史图片仍有预览；原图在上限内可取回；关联关系不因客户端重装丢失。

  - **SR-02.12 过程折叠**
    - **行为**：工具调用与思考过程按轮次折叠为状态行与分组行；点击可展开或收起。运行中显示进行中状态；被停止的轮次保持展开；含图片的工具卡片默认展开，并按图片预览/原图规则展示；过程区状态未确认时给出重试。已作答的问题与答案不参与折叠，按 SR-02.16 单独显示。
    - **验收**：完成轮次可折叠与展开；状态行显示完成状态与耗时；运行中显示进行中；停止轮次不可收起；图片卡片默认展开且不因折叠丢失图片；未确认状态可重试；收起轮次后已作答的问题与答案仍单独可见。
    - **AR-02.12.01 App 过程折叠职责**
      - **模块**：iOS App
      - **职责**：按轮次与活动分组渲染过程，维护展开状态，处理停止轮次与未确认占位。
      - **验收**：折叠与展开可用；状态文案正确；停止轮次保持展开；未确认可重试。

  - **SR-02.13 新建会话**
    - **行为**：可从已有工作区或电脑目录新建会话；选择目录后确认；可在当前目录新建一层文件夹；创建后打开该会话。
    - **验收**：两种入口都能创建；确认后会话打开；目录不存在或创建失败给出原因。
    - **AR-02.13.01 App 新建会话职责**
      - **模块**：iOS App
      - **职责**：选择工作区或目录，确认并打开新建的会话。
      - **验收**：两种入口可用；失败可见。

      - **模块**：中转
      - **职责**：只按路由转发帧，不解析会话内容。
      - **验收**：抓包无内容依赖；内容字段不进入日志。
  - **SR-08.05 关键路径性能基线**
    - **行为**：关键路径先建立可复现基线，再以基线 p95 设定回归阈值；会话列表首屏、文本或图片预览首屏、发送回显、长行滚动与文件下载分别记录，不共用一个固定秒数。基线未建立前不得宣称性能达标或设置硬门禁。
    - **验收**：基线报告记录设备、网络、构建、数据规模与 p50/p95；回归门禁按基线阈值判定；长行可滚动到行尾且不崩溃；下载与首屏分开。
    - **AR-08.05.01 App 性能职责**
      - **模块**：iOS App
      - **职责**：提供可测量的起止点与埋点；不以 UI 自动化步骤耗时替代产品指标。
      - **验收**：每个关键路径有独立指标；基线可复现；回归阈值可判定。
  - **SR-08.06 通知语义**
    - **行为**：同一运行结束或待答事件只通知一次；手机离线时允许丢失、不补发；电脑端新开会话不产生通知。
    - **验收**：重复事件不重复通知；离线不补发；新会话无通知。
    - **AR-08.06.01 App 通知去重职责**
      - **模块**：iOS App
      - **职责**：按事件身份去重，离线不补发。
      - **验收**：重复事件只提醒一次。
    - **AR-08.06.02 中转推送职责**
      - **模块**：中转
      - **职责**：只在手机离线时投递尽力而为的推送，不承诺补发。
      - **验收**：推送不重复；离线丢失可接受。
  - **SR-08.07 主线程卡顿边界**
    - **行为**：在基准设备（当前 iPhone 15 / iOS 27）的开发签名或 TestFlight 构建上，冷启动、会话列表首屏与刷新、流式转写更新三条主线路径不得出现用户可感知的主线程停止：单次阻塞 ≥500 ms 视为不可接受，≥250 ms 的 hang 必须被记录并逐版收敛；弱网、离线与设备发热不作为豁免理由。同一轮输入必须合并为一次状态提交，不得按会话逐条触发观察者失效。
    - **验收**：每条路径至少 30 次采样；系统 HangTracer（500 ms 阈值）报告 0 份；应用内主线程心跳记录 p95 与最大值，≥250 ms 的样本逐版收敛，不设 p95 硬门禁；743 个会话的列表一次刷新只产生 1 次活动状态提交（`revision` +1），不逐会话失效；弱网/离线冷启动同样满足。
    - **AR-08.07.01 App 主线程提交职责**
      - **模块**：iOS App
      - **职责**：把同一轮输入合并为一次状态提交；视图只读已提交状态；不在主线程逐条通知观察者、做全量排序或整份 plist 写入。
      - **验收**：743 会话 `applySessions` 只 +1 revision；冷启动种子写入一次；列表刷新不出现逐条失效。
    - **AR-08.07.02 卡顿证据职责**
      - **模块**：iOS App、发布流程
      - **职责**：提供可复现的主线程卡顿样本与 HangTracer 报告归档；发布前按同一口径检查，不以模拟器代替真机。
      - **验收**：样本记录设备、构建、数据规模、p95/最大值与报告路径；发布前无 ≥500 ms 报告。
  - **SR-08.08 中转告警只报需处理异常**
    - **行为**：中转只为需要人处理的异常产生告警：连接器异常断开（读失败、看门狗或心跳超时、中转判死）、真实服务端 5xx、持续背压丢帧、上游坏字符。连接器计划内停止或重连（正常关闭 1000）、用户离线导致的文件请求失败、正常启停与升级不告警。同一主机同一异常 24 小时最多投递一封，正文累计真实次数；异常恢复后再次发生立即重新告警。
    - **验收**：连续 100 次正常重连 0 封；300 秒内 5 次异常断开 1 封且累计 5 次；持续 3 天的同类异常每天最多 1 封；恢复后再次异常立即重新出 1 封；离线 503 0 封；真实 500 与背压丢帧各 1 封。
    - **AR-08.08.01 异常断开分类职责**
      - **模块**：连接器、中转
      - **职责**：连接器只用 1000 表示计划内停止或重连，看门狗与心跳超时使用可区分的异常关闭码 4003、4004；中转只把非 1000 关闭计入抖动，并保留关闭码、原因与客户端地址。
      - **验收**：正常停止与重连发 1000；看门狗与心跳超时分别发 4003、4004；中转对 1000 不产生抖动告警，对 4003、4004 与 1006 产生。
    - **AR-08.08.02 告警去重与恢复职责**
      - **模块**：中转
      - **职责**：同一主机同一异常按 24 小时去重并累计次数；链路的正常存续达到抖动窗口后视为上一轮恢复，恢复后再次异常立即重新告警；用户离线导致的 503 不计入事故。
      - **验收**：持续异常 24 小时内只 1 封；恢复后再次异常重新告警；累计次数等于真实断开次数；host/offline 503 不告警。

- **IR-09 国际化与本地化**
  - **目标**：所有用户可见面按同一语言策略显示，覆盖支持语言矩阵并可靠回退英语，不出现混排。
  - **成功度量**：矩阵内语言词条完整；切换语言后主要界面完整切换；无硬编码；长文案不溢出；缺译、占位符或布局回归阻断发布。
  - **SR-09.01 语言矩阵与回退**
    - **行为**：产品维护明确的支持语言清单；App、连接器面板与 CLI 按系统或宿主语言选择；未支持语言回退到英语；不得部分翻译后混排。
    - **验收**：矩阵内每种语言可切换；未支持语言显示英语；同一界面无中英混排。
    - **AR-09.01.01 App 语言解析职责**
      - **模块**：iOS App
      - **职责**：按系统首选语言匹配矩阵，支持系统按 App 设置语言，未命中时回退英语。
      - **验收**：首选语言命中时使用该语言；未命中时英语完整；切换后无混排。
    - **AR-09.01.02 连接器与 CLI 语言协商职责**
      - **模块**：连接器
      - **职责**：面板按宿主或浏览器语言选择，CLI 按 `--lang`、`LANG`、系统顺序选择；使用与 App 相同的矩阵和回退。
      - **验收**：面板可随宿主语言切换；CLI 参数优先于环境；未支持语言回退英语。
  - **SR-09.02 端到端语言一致性**
    - **行为**：App、连接器面板、CLI、通知、权限说明、版本与商店元数据使用同一语言策略；技术错误映射为用户文案。
    - **验收**：同一语言下各入口语言一致；英文 App 不显示中文按钮名；权限弹窗与通知随语言变化。
    - **AR-09.02.01 App 文案一致性职责**
      - **模块**：iOS App
      - **职责**：所有用户可见文案走本地化资源，第三方标签与引导文案引用当前语言的产品名。
      - **验收**：英文界面无中文残留；权限说明随语言变化。
    - **AR-09.02.02 连接器面板与 CLI 文案职责**
      - **模块**：连接器
      - **职责**：面板、CLI、状态、Git 与链路错误统一从语言目录取文案，不返回裸中文。
      - **验收**：面板与 CLI 同语言一致；错误可读且可定位。
    - **AR-09.02.03 通知与权限说明职责**
      - **模块**：iOS App、中转
      - **职责**：通知与权限说明在设备侧按当前语言生成；服务端只传事件与参数，不下发固定文案。
      - **验收**：通知标题与正文随语言变化；权限弹窗无固定中文。
  - **SR-09.03 文案资源与翻译流程**
    - **行为**：用户可见文案来自统一资源；禁止硬编码；翻译经提取、机器预填、术语表和版本管理；支持复数与占位符。
    - **验收**：新增文案自动进入资源并报告缺译；占位符或复数错误被拦截；翻译可追溯。
    - **AR-09.03.01 翻译资源与流程职责**
      - **模块**：iOS App、连接器
      - **职责**：维护统一字符串资源与术语表；提取、预填、合并可重复；变更保留版本记录。
      - **验收**：新增文案可追踪到语言资源；缺译与占位符错误可定位；术语一致。
  - **SR-09.04 区域格式与长文案**
    - **行为**：日期、时间、数字、单位按 Locale 格式化；支持长文案、字体与断行；不得使用固定中文或英文格式。
    - **验收**：长文案不截断关键操作；日期与数字符合区域习惯。
    - **AR-09.04.01 区域格式职责**
      - **模块**：iOS App、连接器
      - **职责**：使用系统或 ICU/CLDR 的区域格式；禁止手写 `yyyy-MM-dd`、固定小数点和中文单位。
      - **验收**：日期、数字、单位随区域变化；无固定格式残留。
  - **SR-09.05 自动化质量门禁**
    - **行为**：CI 自动检查缺键、重复键、占位符、复数、硬编码；执行伪本地化与关键界面逐语言截图；缺译或布局回归阻断发布。
    - **验收**：缺键或占位符错误 CI 失败；伪本地化无截断；关键界面逐语言截图可追溯。
    - **AR-09.05.01 本地化质量门禁职责**
      - **模块**：iOS App、连接器、发布流程
      - **职责**：提供词条提取与校验、伪本地化、逐语言 UI 截图与发布前阻断；异常可定位到文件和键。
      - **验收**：门禁可在本地和 CI 重复执行；失败报告包含语言、文件和键。
  - **SR-09.06 用户语言选择**
    - **行为**：默认跟随系统；iOS 支持系统按 App 设置语言；连接器面板随宿主语言实时切换；CLI 支持 `--lang` 与 `LANG`；切换不需重装。
    - **验收**：系统切换后 App 重启生效；面板实时切换；CLI 参数覆盖环境变量。
    - **AR-09.06.01 用户语言选择职责**
      - **模块**：iOS App、连接器
      - **职责**：默认系统语言；提供系统级按 App 选择；面板与 CLI 提供明确的当前语言与切换方式。
      - **验收**：无需重装即可切换；当前语言可见；回退行为可预期。
