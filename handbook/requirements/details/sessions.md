# 会话细节

## SR-02.03 待答提醒与作答

- 已知限制：提问发生时手机未连接，这条提问无法补送；host 侧 pending 随 Agent Context 释放被撤销，App 侧无补救。
- 根因与排查见 `handbook/history/待答丢失根因.md`。
- 诊断日志：`HostEventHub` 的 `hub.ready`、`hub.waterfall`、`hub.cancelled`；启动带 `-DSHViewportProbe` 才落盘。

## SR-02.08 运行结束与待答通知

- App 存活时投递本地通知；手机不在线时由中转发送 APNs，推送里只有会话 id。
- 电脑端新开始的会话无法唤起 App；长时间未答的提问可能丢失。
- 「运行结束时提醒」与「需要确认时提醒」可分别关闭。

## SR-02.12 过程折叠

- 完成轮次可收起，状态行显示「已完成」与耗时；被停止的轮次不可收起。
- 含图片的工具卡片默认展开，不藏在折叠面板后面。
- 尾轮边界未确认时显示占位行：确认中不可点；静置或失败整行可点重试，失败原因包括读取失败、缺一段记录、超时。

## SR-02.13 新建会话

- 目录浏览器每次取一层；文件夹名只允许一层，不能含「/」。
- 新建前二次确认；会话绑定目录后不可更换。

## SR-02.14 会话分组与归档

- 子会话转写默认收起，展开后归在父会话下。
- 归档后仍可打开；当前 DSH 没有取消归档接口。

## SR-02.15 会话状态与活动

- 能力位缺失时隐藏上下文占用、后台任务与子智能体计数。
