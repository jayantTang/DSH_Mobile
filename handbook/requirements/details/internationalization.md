# 国际化与本地化

## SR-09.01 语言矩阵与回退

| 层级 | 语言 | 说明 |
|---|---|---|
| 现有 | `en`、`zh-Hans` | 必须持续保持完整；英语是回退语言 |
| 首批 | `zh-Hant`、`ja`、`ko`、`es`、`pt-BR`、`fr`、`de` | 进入实际翻译、审校与 UI 验收 |
| 候选 | `ru`、`ar`、`hi`、`id`、`vi`、`th`、`tr`、`it`、`nl`、`pl` | 按用户分布和翻译资源逐项启用 |

`ar` 需要 RTL；`ru`、`pl`、`ar` 需要复数规则；`ja`、`ko`、`zh-Hant` 需要字体与断行检查。未在矩阵内的语言统一回退英语，不显示半翻译界面。

## SR-09.02 端到端语言一致性

- iOS App：系统首选语言；支持系统“按 App 设置语言”。
- 连接器面板：宿主 `locale` 服务优先，其次浏览器语言。
- 连接器 CLI：`--lang` > `LANG`/`LC_ALL` > 系统默认。
- 通知与权限说明：设备当前语言；服务端只传事件身份与参数。
- 商店元数据：随 App 语言矩阵发布，通过 ASC API 同步。

## SR-09.03 文案资源与翻译流程

1. 统一字符串资源与校验；修复当前英文残留与中文权限说明。
2. 建立首批语言的翻译、术语表和审校流程。
3. 加入伪本地化、逐语言截图和缺译门禁。
4. 再评估 RTL、复数与候选语言。
