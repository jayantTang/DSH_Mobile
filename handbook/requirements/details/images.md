# 图片变体与降级

对应 `SR-02.07`、`SR-02.11`、`SR-02.12`、`SR-03.03`、`SR-03.04`、`SR-03.05`、`SR-05.03`、`SR-08.02`。

## SR-02.07 图片变体与上传

- 一张逻辑图片最多有两个附件：预览和原图。预览必须有；原图在大小上限内保留。
- 预览：最长边不超过 2560，总像素不超过 4 MP，JPEG/WebP；只用于列表、首次全屏和模型输入。
- 原图：保留上传时的原始字节；单张上限 20 MB。超过上限、格式无法解码或无法安全保存时按文件发送/下载，不静默改写成预览后称为原图。
- 旧数据只有一份附件时，将它视为预览；原图状态为“不可用”，不报错，不伪造原图。

## SR-02.11 图片预览与原图交互

- 列表默认只加载预览；滚动不自动拉原图。
- 全屏先显示预览；存在原图时显示“查看原图”，并显示大小与下载进度。
- “保存原图”与“保存预览”分开；原图下载失败保留预览，可重试；原图缺失时只禁用原图动作。
- 工作区图片：列表用缩略图，全屏和下载读取原文件；不得隐式重编码。
- 桌面 `send_image` 截图与工具结果图片同样遵循预览/原图规则；工具卡片默认展开，不能因过程折叠丢失。

预览与原图都关联到 Host 的会话附件；客户端卸载重装、重新配对或换设备后，历史消息先重新取预览，原图在用户点“查看原图”时再取。原图是否可用只取决于 Host 是否仍保存和在大小上限内，不取决于客户端本地缓存。

## SR-08.02 超限与异常

- 原图超过 20 MB：聊天中按文件显示，提供下载/分享；仍生成预览供气泡和模型使用。
- 原图为空、损坏或 Host 不再保存：显示预览并标记“原图不可用”；重试不反复打满网络。
- 预览失败而原图可用：允许直接查看/下载原图，但必须显式提示正在取原图。
- 网络中断：预览缓存可离线显示；原图下载可续传/重试，失败不删除预览。
