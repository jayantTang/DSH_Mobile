# 产品定位

## 一句话

把电脑上的 DSH 会话接到 iPhone 与 iPad：原生 iOS 客户端、电脑侧连接器、可自建的公网中转。

## 目标用户

在电脑上使用 DSH 的个人用户与开发者。离开电脑后，仍需继续同一会话、处理挂起提问。

## 使用前提

- 电脑已安装并可运行 DSH（`dsh web`）。
- 连接器需要 Node.js 22 及以上。
- 自建中转需要一台有公网 IP 的主机与 Caddy。
- 手机通过 TestFlight 安装 App。

## 范围

关键行为与策略写在 `requirements.md`，本文只界定定位与范围：

- 连接：登记、配对、设备管理、传输（第 1 节）。
- 会话：查看与继续、待答（第 2 节）。
- 工作区：文件与 git 查看（第 3 节）。
- 分发与更新：TestFlight、版本、发布（第 4 节）。

## 非目标

- 不记录实现方案、接口与数据结构；这些随代码演进。
- 不承诺 `requirements.md` 未列出的能力。
