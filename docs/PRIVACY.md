# 隐私说明

**中文** · [English](PRIVACY.en.md)

> 面向：使用者 · 状态：stable · 最近核对：2026-09-20

DSH Mobile 是**你电脑上 DeepSeek Harness 的客户端**。这一页说清楚它碰什么、不碰什么。

## 一句话

**App 不发遥测、不带第三方 SDK，也不会背着你上传任何东西。** 只有你在 App 内主动提交反馈时，
你写的那段正文才会发到中转服务器（见「反馈与通知」）。手机上的会话内容只在你的手机与
你自己的电脑之间传输。

## App 本身

| 项 | 情况 |
| --- | --- |
| 收集的数据 | **无**。没有统计、没有崩溃上报、没有广告 SDK、没有账号体系。只有你主动提交反馈时，你写的正文与随它附上的版本/机型/iOS 会离开手机 |
| 网络请求 | 三条：连到**你自己配置的中转地址**（WSS）；若构建时配置了更新源，会定期向它取一次版本清单（普通 GET，不带任何设备信息）；你主动提交反馈或拉取回信时访问同一台中转（HTTPS）。除此之外不访问任何服务器 |
| 本地存储 | 中转地址、设备令牌、界面偏好。设备令牌与反馈的取件凭据存在系统钥匙串（Keychain）里；会话列表、草稿阅读状态与反馈记录的本地镜像留在本机 |
| 相册/相机 | 只在你主动「发图」时读取你选中的那张，用于上传到你自己电脑上的会话 |
| 通知 | 用于提示任务完成或待回答的提问；实现方式是本机音频保活，不经 Apple 推送服务 |

## 中转服务器

中转是一台**由部署方运维**的公网服务器，作用是让手机和电脑互相找到对方。它：

- **只做鉴权与转发**：看到的是一条条加密通道的元信息（哪台电脑、哪台设备、帧类型），
  **不解析、不存储会话内容**；
- **是 TLS 的终止点**：手机到中转到电脑这两段各自加密，中继本身能看到转发明文。
  所以不要用它传输你不愿意经过第三方的数据；
- **不保留会话历史**：中转落库的只有账号、电脑、设备的登记信息与配对码哈希，
  没有会话消息体。**唯一的例外是你主动提交的反馈与我们的回信**，见下一节；
- **会记录 App 版本**：连接时手机把 App 的版本与构建号报给中转（用于设备列表显示、排查版本问题），
  这是它记录的唯一一条来自 App 的信息，不含会话内容。

中转地址由使用者自己填。你可以：

- 用别人（包括本项目作者）提供的中转，配合对方发的邀请码；
- 或者自己开一台：仓库里的 `relay/deploy/deploy.sh` 是幂等的安装脚本，
  装完那台中转完全由你控制。

## 反馈与通知

意见入口在 App 内的会话列表页，不再跳转到公开的 GitHub 表单。提交与回信的口径：

- 只有你主动点「发送」时才会提交：正文由你撰写，加上 App 自动附上的 App 版本、机型与 iOS 版本；
  发送窗口在提交前把这些内容全部显示出来，你可以放弃。
- 内容存在**你使用的那个中转服务器**上（自建就是你自己那台），用途是让我们看到你的意见并回信；
  不公开、不做统计分析、不进第三方 SDK。
- 不上传会话内容、转写文本或任何文件。
- 提交后手机会拿到一个「取件凭据」，存在系统钥匙串里，用来取回我们的回信与通知；删掉 App 后
  凭据仍在，重装 App 后这些记录还能看到（这是为了让回信不至于跟着一次重装一起丢）。
- 保留与删除：反馈与回信暂不自动删除。需要删除请按下面的「数据删除」联系运维方，
  由其在服务器上删掉对应记录。

崩溃报告是这条通道上唯一**自动**发出的内容，口径单独写清楚：

- 只有 App 上一次真的崩了才会产生。iOS 把崩溃诊断交给 App 的**下一次启动**，App 在那一刻
  把它存到本地，随后联网时投递；同一构建上的同一个崩溃只发一次。
- 内容只有技术事实：App 版本与构建号、机型、iOS 版本、异常类型与信号，以及崩溃时的调用栈
  帧（二进制名 + 偏移，经 dSYM 才能还原成符号名）。**不含**会话 id、消息正文、文件路径、
  账号或设备令牌。
- 存本地时最多保留 20 条，发出去即标记；发不出去就留在本地等下次，不做重试风暴。
- 不想让它自动发：撤销该设备的配对（设置 → 已配对的设备 → 撤销）后，App 没有可用的中转凭据，
  报告只会留在本机。

## 数据删除

- 手机上：设置 → 已配对的设备 → 撤销；或直接删除 App，令牌随之消失。
- 电脑上：删除 `~/.dsh/mobile-link/agent.json` 即注销本机在中转上的身份。
- 中转上：请中转的运维方（自建的话就是你自己）用 `admin.py device-revoke` /
  `agent-disable` 撤销。
- 中转上的反馈与回信：同样由运维方删除对应记录。手机上设置里的「清除本地缓存」会清掉反馈记录的
  本地镜像（下次打开重新拉取），钥匙串里的取件凭据保留——**App 内没有单独删除这份凭据的入口**，
  它会随设备抹掉而消失。
